# Icon Candidates

- `CloudChevron.svg`: the cleanest menu bar read. Feels cloud-first and stays legible small.
- `CloudPrompt.svg`: the most code-forward option. Slightly busier, but still compact.
- `CloudGate.svg`: the softest and most "cloudy" silhouette. Friendlier, less technical.
- `CloudPulse.svg`: leans into the status-bar idea with a pulse/wave cutout.

For the current menu bar layout, `CloudChevron.svg` is the safest default and `CloudGate.svg` is the softest alternative.
